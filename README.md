# MA ANFA Shopify Theme Starter
A premium-inspired Shopify Online Store 2.0 starter theme.

Includes a responsive header/footer, homepage hero and featured collection section, with a warm cream, date-brown and muted-gold palette.

This is a starter, not a finished live store. Add real product photos, product pages, policies, navigation, shipping, taxes and payment settings in Shopify. Preview carefully before publishing.
